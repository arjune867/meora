# MÉORA Skincare Landing Page

Landing page statis berbahasa Indonesia untuk MÉORA Papua Red Fruit Moisturizer dan MÉORA Bloom Serum.

## Struktur proyek

```
meora/
├── index.html
├── README.md
└── assets/
    ├── meora-bloom-serum.jpg
    ├── meora-moisturizer.jpg
    └── nusantara-natural-logo.svg
```

## Fitur

- Desain responsif untuk mobile, tablet, dan desktop.
- Tampilan minimalis bernuansa cream, blush, dan terracotta.
- Foto produk asli.
- Identitas visual Nusantara Natural sebagai logo dan favicon.
- CTA WhatsApp, Shopee, dan TikTok Shop.
- Metadata SEO, Open Graph, dan FAQ.
- Tanpa framework atau dependensi build; dapat dihosting sebagai situs statis.

## Menjalankan lokal

Buka `index.html` di browser atau jalankan server statis dari root proyek, misalnya:

```bash
python -m http.server 8000
```

Lalu kunjungi `http://localhost:8000`.

## Perbarui tautan

Tautan WhatsApp, Shopee, dan TikTok Shop ada di `index.html`. Periksa tautan marketplace secara berkala agar mengarah ke halaman produk yang benar.

## Catatan

Pastikan informasi manfaat, bahan, izin edar, dan klaim produk sesuai dengan label serta dokumen resmi produk. Canonical URL sebaiknya ditambahkan setelah domain produksi ditetapkan.
